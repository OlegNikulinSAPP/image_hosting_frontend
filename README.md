# Хостинг изображений (IMAGE HOSTING)
## Обзор
IMAGE HOSTING — это проект, который позволяет пользователям загружать изображения и получать на них прямые ссылки для общего доступа.

# Быстрый старт с Docker
Для быстрой настройки и запуска приложения с использованием Docker выполните следующие действия:

### 1. Соберите и запустите Docker-контейнер

```bash
docker-compose up --build
```
Хостинг изображений будет доступен по адресу http://localhost:8080/

# Установка
Предварительные требования
Python 3.12

Docker и Docker Compose (рекомендуется)

Библиотека Pillow

# Инструкции по установке
Клонируйте репозиторий:
```bash
git clone https://github.com/OlegNikulinSAPP/image_hosting_frontend.git
cd cd image-hosting-frontend
```
Установите зависимости:
```bash
pip install -r requirements.txt
```
Запустите сервер разработки:
```bash
python app.py
```
API будет доступно по адресу http://127.0.0.1:8000/.

# Использование
Пример запроса
Загрузка изображения:

```bash
curl -X POST http://localhost:8000/upload \
  -F "file=@test.jpg"
```
 ## Получение изображения:

Перейдите по ссылке вида: http://localhost:8080/images/{имя_файла}

Структура проекта
```text
project/
├── static/                # Статические файлы фронтенда
│   ├── index.html         # Главная страница
│   ├── style.css          # Стили
│   ├── script.js          # Клиентский JavaScript
│   └── images/            # Фоновые изображения
├── images/                # Загружаемые пользователями изображения
├── logs/                  # Логи приложения
├── app.py                 # Python-бэкенд
├── requirements.txt       # Зависимости Python
├── Dockerfile             # Конфигурация Docker для бэкенда
├── docker-compose.yml     # Конфигурация Docker Compose
└── nginx.conf             # Конфигурация Nginx
```
## Особенности
Загрузка изображений через интерфейс или API

Автоматическая обработка изображений с помощью Pillow

Оптимизация и изменение размера загружаемых изображений

Генерация прямых ссылок на изображения

Интуитивно понятный веб-интерфейс

Разделение статики (Nginx) и динамического контента (Python)
